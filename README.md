# Análise de Chuva Anual em Python

Um sistema completo de análise de dados climáticos — automatizado, organizado e fácil de entender. Vamos explorar como o código funciona por dentro.

### Por que automatizar a análise de chuva?

#### Análise manual
Calcular médias, máximos e mínimos à mão para 12 meses é lento e propenso a erros.

#### ⚠ Risco humano
Um número digitado errado pode comprometer toda a análise climática.

#### 💡 Solução Python
O programa automatiza cálculos, valida entradas e exibe resultados em segundos.

---

### O que o programa faz?

#### Processo:
- **Calcula**: Soma, média, máximo, mínimo das precipitações mensais.
 
#### Gráfico:
- **Desenha barras** █ no terminal, representando a quantidade de chuva.

#### Entrada:
- **Recebe**: 12 meses de dados de precipitação via `input()`.

#### Relatório:
- **Exibe**: Resultados organizados, como soma total, média, valores máximos e mínimos.

---

O código transforma dados brutos de precipitação em informações organizadas — do `input()` do usuário até o gráfico de barras no terminal.
